# Asteroids Game

This is a beta version of asteroids game. Score counter feature to be added in next update.

## BETA VERSION FEATURES

You can launch the main.py through uv project manager (remember to initialize a virtual environment before-hand) to play a classic game of asteroids. Beta version features included.

- Player movement through w-a-s-d
- Shoot using space-bar
- 3 different kinds of asteroid enemies (Small-Medium-Large). Shooting any enemy creates two smaller and faster enemy. Shooting the smallest destroys it.
- Shots are fired at 0.3s per shot.

## NEXT UPDATE FEATURES

We're working on the next update. The features in version 1.0 include but are not limited to:

- Scoring system: Shooting smallest enemy earns you 4 points, shooting down medium earns you 2 points and largest gets you 1.
- Leaderboard system: We're working on a leaderboard system that'd display the top 5 high-scores in an retro arcade style leaderboard where you enter your name after the game ends to register your score.
- Visual updates: We're working on some visual features such as score display, visual effects for enemy split or destroy.
- Audio updates: We're working on adding some sound effects for shooting enemies, hitting an enemy, game start and over.
- Webpage deployment for playing among friends.
- And many more quality of life updates.
